About KnowledgeForge AI

Turn your documents into intelligent quizzes.

Project Mission

KnowledgeForge AI was engineered to bridge static educational literature and dynamic self-assessment. By extracting readable text from lecture notes, syllabi, and research documents, the application prompts Google Gemini AI to distill core conceptual ideas into high-yield multiple choice questions.

Instead of memorizing sentences, learners receive conceptual scenarios, detailed rationale for every option, and topic-specific strength and weakness evaluations.

System Architecture & Tech Stack

1. Frontend (Vanilla HTML5, CSS3, JavaScript)

Zero bloated frameworks. Pure, performant semantic HTML5, custom modern SaaS CSS with responsive media queries, and vanilla JavaScript. Features animated drag-and-drop file ingestion, asynchronous multi-step progress indicators, and an interactive quiz runner.

2. Backend (C++ Crow Framework)

High-performance, lightweight REST API architecture built in modern C++17 using the Crow HTTP framework. Handles multipart file uploads, PDF/TXT extraction, text normalization, and JSON persistence without requiring heavy database dependencies.

3. AI Integration (Google Gemini API)

Server-side prompt orchestration ensuring API keys are never exposed to client-side scripts. Enforces strict JSON response schemas and validates that every generated question has exactly 4 options, a valid 0–3 correct index, and a clear explanatory rationale. Designed with an abstract IAIService interface to easily accommodate OpenAI or other providers.

4. Document Processing & Chunking

Includes text sanitation, blank-line elimination, and paragraph chunking to safeguard API token budgets. Accurately verifies readable text and warns users when scanned image-only PDFs are provided.

REST API Specification

Method Endpoint Description
POST /api/upload Uploads PDF/TXT, extracts text, returns unique fileId
POST /api/generate-quiz Generates structured multiple-choice quiz questions from text
POST /api/submit-quiz Evaluates user answers, computes score and topic analysis
GET /api/history Retrieves saved quiz completion records
DELETE /api/history/:id Deletes a specific quiz record by ID
GET /api/health Returns service health and status info
